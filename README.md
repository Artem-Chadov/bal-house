# Bal House — многостраничный сайт

Статический сайт. Главная страница — index.html; стили, шрифты, фотографии и JavaScript размещены в assets.

GitHub Pages: ветка main, корень репозитория. Сайт публикуется отдельно от анкеты.

20 страниц: проекты, направления строительства, объекты, компания и контакты. Кнопки обсуждения открывают переписку Bal House во ВКонтакте.

Ответы из брифа и личные данные заказчика в репозиторий не включены.
